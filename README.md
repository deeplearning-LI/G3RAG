# 🌐 Geometric Gain Graph

> **Geometric Gain Graph: Zero-Token Graph Construction for Multi-Hop RAG**  
> 📝 A zero-token graph construction method for Multi-Hop Retrieval-Augmented Generation (NeurIPS 2026 Poster).

## 📂 Project Structure

```text
.
├── 📄 geo_gain_graph.py      # Main entry: core logic for geometric gain graph (Zero-Token graph construction, etc.)
├── 📁 results/               # Experimental results and model evaluation data
│   ├── 📁 NV2/               # NV2 results (contains hotpotqa.jsonl, musique.jsonl, etc.)
│   └── 📁 Qwen3/             # Qwen3 results
└── 📁 tools/                 # Core tool modules
    ├── 🧩 embedding_function.py  # Text embedding wrapper
    ├── 💬 prompts.py             # LLM prompt templates
    ├── 📝 rag_qa_template.py     # RAG standard pipeline
    ├── 🔄 rerank.py              # Text relevance reranker
    └── ⚙️ setup_logger.py        # Logger configuration
```

## 🚀 Core Features

- **Zero-Token Graph Construction**: Innovatively builds the "Geometric Gain Graph" without relying on LLMs for node/edge extraction, achieving zero-token cost and extremely fast graph construction.
- **Innovative Retrieval Strategy**: Utilizes geometric gain mechanisms during retrieval to precisely capture implicit multi-hop relationships and semantic structures across documents.
- **State-of-the-Art (SOTA) Performance**: Significantly outperforms existing state-of-the-art multi-hop RAG baselines, including **HippoRAG2** and **LinearRAG**, achieving the optimal reasoning accuracy with the highest computational efficiency.

## 🛠️ Quick Start

1. **Install Dependencies:** Please install the required libraries for this project, including `vllm`, `igraph`, `numpy`, and `openai`:
   ```bash
   pip install vllm igraph numpy openai
   ```
2. **Run the Experiment:**
   ```bash
   python geo_gain_graph.py
   ```

## 📊 Datasets

Currently, the `results` directory primarily tracks and evaluates the following multi-hop datasets (sourced from the processed versions provided by **HippoRAG**):
- 📚 **HotpotQA**
- 🎵 **MuSiQue**
- 📖 **2WikiMultiQA**

## 🔍 G<sup>3</sup>RAG Result Details

This project logs the final outputs of the G<sup>3</sup>RAG pipeline (refer to the `.jsonl` files in the `results/` directory). The logged details include:
- **Retrieved Documents**: The crucial supporting paragraphs efficiently retrieved along the geometric gain pathways.
- **Model Reasoning Answers**: The reasoning texts and final predicted answers generated by the LLMs based on the retrieved contexts.
